# Noderra Coaching Institute Website Demo

A premium, futuristic coaching institute website concept built using plain HTML, CSS and JavaScript.

## Preview
Extract the ZIP and open `index.html` in Chrome. Internet access is needed for Google Fonts and remote Unsplash photography.

## Included
- Responsive desktop, tablet and mobile layouts
- Animated hero, orbital graphics, floating cards and scroll reveals
- Program category filters
- Coaching approach / learning journey section
- Mentor profiles
- Animated demo statistics
- Interactive testimonial carousel
- Free counselling enquiry form
- Noderra logo watermark in hero, method section and footer
- Reduced-motion accessibility support

## Before presenting to a real institute
- Replace sample program names, course details and durations with accurate information.
- Replace fictional mentor names and photos with approved real profiles.
- Replace illustrative metrics and sample testimonials with verified institute data. Do not represent demo claims as actual results.
- Update `hello@example.com` in `js/main.js` and the phone number/email in `index.html`.
- The form uses `mailto:` and does not save leads. Connect a backend, CRM or form service for production.
- Replace remote Unsplash images with licensed client-approved photography.
